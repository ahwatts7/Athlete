NOTIFICATION SETUP
Step 1 — Create the Automation
1
Open the Shortcuts app on your iPhone. Tap the Automation tab at the bottom of the screen.
2
Tap + in the top right → tap New Automation.
3
Scroll down, tap Time of Day. Set the time to 7:00 AM. Set repeat to Daily. Tap Next.
Step 2 — Build the Day Logic
4
Tap Add Action. Search "Current Date" and add it. Then add another action: search "Format Date". Set format to Custom and type EEEE — this outputs the full day name like "Monday".This is the engine that detects what day it is automatically.
5
Add action: search "If" and add the If block. Set it to: Formatted Date → contains → Monday.
6
Inside the If block, add action: "Show Notification".

Title: Upper Body Day 💪
Body: Don't forget to do your workout — track it in ATHLETE
Leave "Play Sound" on so it actually alerts you.
7
Also inside the If block, add action: "Open URL". Paste the URL of your saved ATHLETE file. (Open the file in Safari → long press the address bar → Copy → paste here.)When you tap the notification, this opens the app directly.
8
Tap Otherwise at the bottom of the If block. Add another If for each remaining day. Repeat steps 5–7 with these titles:
TuesdayPull Day + Legs 🦾
WednesdaySoccer & Conditioning ⚽
ThursdayUpper Body Volume 💪
FridayLower Body + Explosives 🦵
SaturdayActive Recovery 😴
SundayGame Day 🏆
Body for every day: Don't forget to do your workout — track it in ATHLETE
Step 3 — Finalize
9
When all 7 days are set up, tap Next in the top right. On the summary screen, find the toggle that says "Ask Before Running" and turn it OFF.This makes it fully automatic — no confirmation required every morning.
10
Tap Done. Every morning at 7am you'll get a notification with your workout type for that day. Tapping it opens ATHLETE directly. Zero extra steps.
